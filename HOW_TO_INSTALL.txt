BEE INTERACTION DETECTOR - HOW TO INSTALL AND RUN
=================================================

What you need:
  - An internet connection for the first install (about 3 GB is downloaded).
  - About 6 GB of free disk space.
  - Installing takes 10-20 minutes, and you only do it once.


WINDOWS
-------
1. Unzip the file you downloaded: right-click it > "Extract All...".
   Extract it to a short location, for example:  C:\BeeDetector
   (Avoid OneDrive folders.)

2. Open the extracted folder and double-click:  Install-Windows.bat

   If a blue "Windows protected your PC" window appears,
   click "More info" and then "Run anyway".

3. A black window shows the progress. Wait until it says
   "Installation complete", then press any key to close it.

4. Start the program with the "Bee Interaction Detector" icon on your
   Desktop (it is also in the Start menu).


MAC
---
1. Double-click the downloaded zip file to unzip it, and move the extracted
   folder to where you want to keep it (for example, your Documents folder).

2. Open the folder and double-click:  Install-Mac.command

   If macOS says the file can't be opened / "Apple could not verify" it:
     a. Click "Done" (or "OK").
     b. Open System Settings > Privacy & Security.
     c. Scroll down and click "Open Anyway" next to "Install-Mac.command".
     d. Confirm by clicking "Open Anyway" again (enter your password if asked).

3. A Terminal window shows the progress. Wait until it says
   "Installation complete", then close the window.

4. Start the program with the "Bee Interaction Detector" icon on your Desktop.


USING THE PROGRAM
-----------------
1. Click "Run Pipeline".
2. Drop a video onto the box (or click "Browse...").
3. Click "RUN PIPELINE" and wait. On a typical laptop, a 2-minute video
   takes about 10-15 minutes.
4. When it finishes, click "Open Folder" to see the results.
   All results are saved in the "output" folder inside the program folder.


GOOD TO KNOW
------------
- Don't move or rename the program folder after installing. If you do,
  run the installer again from the new location.
- To update to a new version: unzip the new version, run its installer, and
  then delete the old folder.
- To uninstall: delete the program folder and the Desktop icon.
- If the Desktop icon is missing, double-click Start-Windows.bat or
  Start-Mac.command in the program folder.
- If something goes wrong, send the person who gave you the program a
  screenshot, and the file  .tools/gui.log  from the program folder.
  (On Mac, press Cmd+Shift+. in Finder to show hidden folders like .tools.
   On Windows, the .tools folder is visible normally.)
